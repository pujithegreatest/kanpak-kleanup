How to run the real demo

  1. Download or clone this repository.
  2. Open the folder on a Windows computer with Python installed.
  3. Double-click Start Server.bat.
  4. Use the browser page that opens at http://127.0.0.1:5088.

GitHub Pages cannot run the Python backend or SQLite database, so this preview uses browser storage only.
